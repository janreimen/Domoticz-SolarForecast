# Support

This is a community-maintained Domoticz plugin, provided on a best-effort basis.

## Before asking for help

1. Read the [README](README.md), [FAQ](docs/FAQ.md), and [Troubleshooting](docs/TROUBLESHOOTING.md).
2. Confirm the plugin version (`0.0.4`), Domoticz version, and Python version.
3. Run the offline test suite and compilation checks.
4. Check the Domoticz log around plugin startup and a forecast refresh.
5. Remove API keys, VINs, public IPs, account identifiers, precise home coordinates, and other private details from logs before posting.

## Where to ask

- **Bug:** open an issue using the bug report template.
- **Enhancement:** open an issue using the feature request template.
- **Usage question:** use the question issue template if enabled, or start a discussion if GitHub Discussions is enabled.
- **Security concern:** follow `SECURITY.md`; do not post it publicly.

Please include a minimal reproduction and expected versus actual behavior. Do not expect immediate responses or guaranteed support for old releases.
