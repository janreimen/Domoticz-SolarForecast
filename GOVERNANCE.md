# Project governance

## Current status

This is an early-stage community project. Release `0.0.2` is the current documented version. Maintainer availability is best-effort and no response-time guarantee is implied.

## Decisions

Small, low-risk fixes may be handled directly by maintainers. Larger changes should be discussed in an issue before implementation. Decisions should prioritize correctness, safe handling of credentials, predictable Domoticz behavior, clear forecast semantics, backward compatibility, and testability.

## Maintainer and repository ownership

- Project maintainer: Jan Reimen
- Canonical repository: https://github.com/janreimen/Domoticz-SolarForecast

The GitHub account `janreimen` is the intended repository owner. GitHub repository permissions remain authoritative; repository files alone cannot change GitHub ownership. No maintainer role is implied by submitting an issue or pull request.

## Changes to this policy

Governance may evolve as the contributor community grows. Changes should be discussed openly and recorded in version control.
